# Termos de uso — minuta inicial

Este documento é uma minuta informativa para o Caderno de Contas, concebido,
desenvolvido e mantido por Bianca Moura. Deve ser revisado e complementado antes
de oferecer o sistema a terceiros; não substitui orientação jurídica.

## Acesso e autorização

O acesso ao sistema é destinado a pessoas autorizadas pela responsável pela
implantação. Criar uma conta ou conseguir acessar uma URL pública não concede
licença para copiar, reproduzir, distribuir, sublicenciar ou comercializar o
sistema.

## Uso do sistema

Use o sistema somente para sua finalidade de organização financeira e de acordo
com a legislação aplicável. A pessoa usuária é responsável por proteger suas
credenciais e pela exatidão das informações que inserir.

## Propriedade intelectual

O código e os materiais originais permanecem protegidos por direitos autorais.
Componentes de terceiros continuam sujeitos às suas próprias licenças.

## Privacidade e implantação

Antes de habilitar o acesso de terceiros, a responsável pela implantação deve
publicar um aviso de privacidade que explique o tratamento de dados na
implantação específica. Este documento não descreve nem substitui esse aviso.
